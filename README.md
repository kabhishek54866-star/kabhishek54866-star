### 🚂 RailConnect — Full-Stack Railway Booking Platform

<img src="https://img.shields.io/badge/Spring_Boot_3.4-6DB33F?style=flat-square&logo=spring-boot&logoColor=white"/> <img src="https://img.shields.io/badge/React_19-20232A?style=flat-square&logo=react&logoColor=61DAFB"/> <img src="https://img.shields.io/badge/MySQL_8-005C84?style=flat-square&logo=mysql&logoColor=white"/> <img src="https://img.shields.io/badge/MongoDB_7-4EA94B?style=flat-square&logo=mongodb&logoColor=white"/> <img src="https://img.shields.io/badge/Redis_7-DC382D?style=flat-square&logo=redis&logoColor=white"/> <img src="https://img.shields.io/badge/Docker-2496ED?style=flat-square&logo=docker&logoColor=white"/>

> Built out of frustration with IRCTC — a production-grade alternative with real engineering decisions behind every component.

| Feature | Implementation |
|---|---|
| **Tatkal Booking** | Pessimistic row-level locking (`PESSIMISTIC_WRITE`) on `seat_availability` — prevents double-booking under concurrent load |
| **CNF/RAC/WL** | Automatic seat assignment with proper RAC queue and waitlist per class (SL, 3A, 2A, 1A) |
| **Multi-DB Design** | MySQL for ACID transactions · MongoDB for reviews & analytics · Redis for autocomplete cache |
| **JWT Auth** | Access tokens in memory · Refresh tokens in httpOnly cookies · Axios interceptor for silent renewal |
| **Live Tracking** | WebSocket (STOMP over SockJS) broadcasting train coordinates every 30s |
| **Migrations** | Flyway V1–V16 — schema versioned and reproducible, `ddl-auto=validate` in dev |
